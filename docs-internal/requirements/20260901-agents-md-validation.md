# PRD: AGENTS.md Validation + Cross-Cutting Path Hygiene

**Date**: 2026-09-01
**Status**: in-progress
**Scope**: New scanner for validating `AGENTS.md` files (binding
contract structure) and a cross-cutting path hygiene scanner that
checks all committed files for absolute home paths and AI attribution
boilerplate.

## File Types Covered

| File type | Count | Scanner |
|-----------|-------|---------|
| `AGENTS.md` / `CLAUDE.md` / `AGENT.md` | ~56+ | agents_md |
| All text files | all | path_hygiene |

## Rules

### agents_md (check name: `agents_md`) — NEW SCANNER

- [ ] `agents-md-usage-protocol` — `AGENTS.md` should contain a "Usage Protocol" section describing the binding contract nature. **Severity: info.** Auto-fixable: no.
- [ ] `agents-md-jit-index` — `AGENTS.md` should contain a "JIT Index" or similar table of contents for quick navigation. **Severity: info.** Auto-fixable: no.
- [ ] `agents-md-no-absolute-paths` — `AGENTS.md` must not contain absolute filesystem paths (`/Users/...`, `/home/...`). **Severity: warning.** Auto-fixable: no.
- [ ] `agents-md-no-ai-attribution` — `AGENTS.md` must not contain "Generated by", "Co-Authored-By: Devin", or similar AI tool attribution. **Severity: error.** Auto-fixable: yes (strip).
- [ ] `agents-md-child-chain` — If `AGENTS.md` references child `AGENTS.md` files, those files should exist. **Severity: warning.** Auto-fixable: no.

### path_hygiene (check name: `path_hygiene`) — NEW SCANNER

- [ ] `no-absolute-home-paths` — No committed file should contain `/Users/<username>/` or `/home/<username>/` paths. **Severity: warning.** Auto-fixable: no. **Note**: Excludes `.envrc`, `.gitignore`, and config files that legitimately reference home paths.
- [ ] `no-ai-attribution` — No committed file should contain "Generated with [Devin]", "Co-Authored-By: Devin", or similar AI tool attribution boilerplate. **Severity: error.** Auto-fixable: yes (strip).
- [ ] `no-ai-signature-comments` — No committed file should contain AI tool signature comments in source code headers. **Severity: error.** Auto-fixable: yes (strip).

## Configuration

```toml
[scanner_config.agents_md]
require_usage_protocol = false  # info-level, not enforced
require_jit_index = false
check_child_chain = true

[scanner_config.path_hygiene]
check_absolute_home = true
check_ai_attribution = true
exempt_files = [".envrc", ".gitignore", "*.env"]
attribution_patterns = ["Generated with [Devin]", "Co-Authored-By: Devin", "Generated by AI"]
```

## Acceptance Criteria

- [ ] Both scanners exist with `scan()` returning `Vec<ScannerIssue>`
- [ ] Both registered in `mod.rs`, wired in `lint.rs`, config in `config.rs`, documented in `AGENTS.md`
- [ ] `path_hygiene` scanner checks all text files but respects exempt list
- [ ] `path_hygiene` scanner uses centralized exclusion list
- [ ] Tests for each rule
- [ ] Smoke test: `agents_md` fires on repos with AGENTS.md files
- [ ] Smoke test: `path_hygiene` detects AI attribution in test files
- [ ] `devbox run -- just quality` passes

## Out of Scope

- **AGENTS.md content quality** — validating the actual guidance quality is a job for the `ai-guidance-improver` skill, not a linter.
- **CLAUDE.md / AGENT.md format differences** — these are treated as aliases for AGENTS.md. Format-specific validation is out of scope.

## Dependencies

- **Centralized exclusion list** — `path_hygiene` must not scan `node_modules/`, `target/`, etc.
